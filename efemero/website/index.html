Infraestrutura Efêmera Serverless

Ambiente que só
existe quando necessário.

Uma arquitetura AWS projetada para provisionar infraestrutura sob demanda após um acesso considerado válido e removê-la automaticamente após um período configurável sem novos acessos. A solução combina Infrastructure as Code, automação operacional e otimização de custos, mantendo custo ocioso zero na camada efêmera e custo de uso aproximadamente zero para o volume atual de acessos.

O Problema

Ambientes de demonstração e portfólios técnicos costumam permanecer ativos continuamente, gerando custos mesmo quando não estão sendo utilizados. Este projeto explora uma abordagem diferente: tratar a infraestrutura de apresentação como um recurso temporário, criado apenas quando necessário e removido automaticamente após seu uso.

O resultado é uma arquitetura que elimina custo ocioso na camada efêmera e mantém o custo em uso aproximadamente zero no cenário atual, sem abrir mão de automação, rastreabilidade e controle operacional.

Principais Características
  • Provisionamento sob demanda: acessos considerados válidos acionam automaticamente o processo de criação da infraestrutura.
  • Ciclo de vida automatizado: AWS Lambda, DynamoDB, EventBridge e GitHub Actions coordenam a criação, manutenção e remoção dos recursos.
  • Autenticação segura: integração entre GitHub Actions e AWS usando OIDC, sem chaves estáticas de longa duração.
  • Infraestrutura como Código: os componentes temporários são definidos e gerenciados por Terraform.
  • Otimização de custos: a camada efêmera não permanece ativa em idle e o custo em uso é aproximadamente zero para o volume atual de acessos.
